## 🌌 Overview

## ⚡ Windows 11 Native Desktop Features

- **Fluent 2 Design & Mica Material**: Frameless desktop window with translucent glass backdrop, rounded corners, and glowing Stark Mark-86 cyan & gold HUD accents.
- **Custom Windows 11 Titlebar**: Integrated with quick provider switching, token limit meters, always-on-top pin (`📌`), and native minimize/maximize/close controls.
- **Left Navigation Rail**: 1-click access to Chat, AI Nexus, Stark Protocols, Vision/OCR Lab, Neural Vault, Hardware Telemetry, Voice Synthesis, and Settings.
- **Token Budget Optimizer**: Low-Token Mode toggle and sliding-window context compression to minimize API token consumption and boost responsiveness.
- **Global Summoning Shortcut**: Summon JARVIS anywhere on Windows by pressing `Ctrl + Shift + J`.
- **System Tray Integration**: Background tray daemon with quick action sweep and diagnostics.
- **3D Holographic Avatar & Arc Reactor**: Three.js WebGL particle avatar and pulsing Arc Reactor core.
- **Edge TTS & Piper Voice**: Natural British & Persian spoken voice output with live waveform visualizer.

## 🚀 How to Run Native Desktop

### 1. Quick Launch (Recommended)
Simply double click:
```cmd
start_desktop.bat
```

### 2. Manual Command Line
```powershell
# Install Node and Python dependencies
npm install
pip install -r requirements.txt

# Start Native Windows 11 Desktop Application
npm start
```
